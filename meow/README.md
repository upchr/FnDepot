# 猫窝 Meow（影视仓）

跨端影视客户端：**Web / PC / TV 一套内核**。本 FnDepot 应用是其中的 **fnOS 原生服务端**
（无头 Rust 壳 + Java 后端），装好后从应用中心打开即为 Web 界面。

## 依赖

- **java-21-openjdk**（应用中心安装，约 340 MB）
- 未装 Java 时应用仍可安装，但影视后端不会启动；装好后启动应用即可

## 端口

| 端口 | 用途 |
|---|---|
| 30010 | Web 界面（对局域网开放，应用中心入口） |
| 30011 | 后端 API（仅绑定 127.0.0.1，不对外） |

## 数据目录

数据、插件与日志都在应用自身目录（`var/`）下，升级应用不会清除：

- `var/data` —— 站点配置、片库索引、缓存
- `var/plugins` —— 插件
- `var/logs/meowd.log` —— 启动日志
- `var/etc/meow.conf` —— 端口配置

## 功能

- 聚合搜索：一处搜索多个第三方内容源
- 详情与播放：线路切换、播放进度、收藏与历史
- 弹幕聚合（可选，需自行配置弹幕服务）
- drpy JS 源运行时（插件形式，按需安装）
- 片库与离线缓存

## 说明

- **本项目不提供任何内容源**。影视内容、站点配置与弹幕数据均来自第三方，由用户自行导入；
  本项目只提供播放与加载能力，用户自行承担合规责任。
- 架构区分 `x86` 与 `arm` 两个安装包，装错架构会启动失败，请按设备实际架构选择。
